Overview

  • A nightly job that logs into every switch, router, and firewall, pulls the running config, and commits it to a private Git repo so every change has a diff and a timestamp.

    Why

    Most outages I've chased came down to a change nobody remembered making. With configs in version control, “what changed?” becomes a one-line command.

    What's next

    Alerting on unexpected diffs, and a read-only web view that renders each device's history as a table.
