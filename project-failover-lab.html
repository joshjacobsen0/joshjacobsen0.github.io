Overview

  • A two-ISP test bed built to answer one question: how fast can a home network notice a dead uplink and move traffic to the backup?

    Method

    Pull the primary WAN cable while pinging a public address and measure how many replies go missing. Repeat with different detection settings.

    Results

    Default link-state detection took several seconds. BFD with 100 ms timers and a tuned BGP session cut the gap to roughly 300 ms.

Results

  • Defaults ~6 s
  • Fast timers ~1.2 s
  • BFD 100 ms ~300 ms
