  • PlatformiPhone 5, iOS 6
  • LanguageObjective-C

Overview

  • An experiment in making a 2012 iPhone useful again: a native chat client for a modern AI model, built against the iOS 6 SDK with the classic skeuomorphic look.

    The hard part

    Old TLS stacks can't talk to modern APIs directly, so requests go through a small relay that handles the handshake and streams responses back.

    What's next

    Message history, push notifications, and a proper app icon with that glossy shine.
